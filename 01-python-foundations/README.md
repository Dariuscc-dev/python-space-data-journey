# Phase 1 — Python Foundations

## Goal

Build the logic needed to write small Python programs independently: variables, control flow, data structures and functions.

## Why this matters

Every future data pipeline, API, scraper or ML model depends on these basics. This is the slowest phase to rush and the most important to master properly.

## Source material

- 30 Days of Python (Asabeneh): days 1 to 14, used as a topic checklist, never copied
- Official Python tutorial and documentation
- My own exercises, invented on top of the same concepts

## Contents

- Variables and data types
- Operators
- Strings
- Lists, tuples, sets
- Dictionaries
- Conditionals
- Loops
- Functions and scope
- Modules
- Comprehensions (only after mastering plain loops)

## Final mission: Space Calculator

A command-line tool for astronomical conversions and basic orbital comparisons. I decide the menu, the data structures used to store planet data, and which conversions and comparisons it supports. No template or solution is used; the design is mine.

Possible directions (not a spec, just inspiration):

- Convert between km, miles, AU and light-years
- Compare gravity, radius, mass or orbital period between planets
- Calculate light travel time between two distances
