# Phase 5 — APIs and Data Collection

## Goal

Build simple, reproducible and responsible pipelines that collect real data from the outside world.

## Source material

- 30 Days of Python (Asabeneh): days 22 and 28 as a checklist for scraping and APIs
- Official Python documentation for urllib/http basics
- requests library documentation
- BeautifulSoup documentation, used responsibly and only where scraping is permitted

## Contents

- HTTP basics: methods, status codes, headers
- JSON parsing
- The requests library
- Consuming public APIs: pagination, rate limits, authentication basics
- Environment variables for API keys (never committed)
- Responsible web scraping when no API exists
- Saving results to CSV, JSON or SQL

## Final mission: Space Data Pipeline

A program that, on demand or on a schedule: queries a public source related to space, aviation, engineering or nature; saves the raw response; extracts the relevant fields; validates anomalous values; stores clean data in a database; produces a summary or chart. The goal is a repeatable process, not a one-off script.
