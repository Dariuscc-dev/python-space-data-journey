# Learning Contract

## My objective

I am learning Python and SQL to become capable of designing, debugging and building data-driven software independently, all of this by the old-fashioned way: reading official documentation, experimenting, failing and fixing my own mistakes.

## Rules

1. I attempt every exercise and project alone before seeking help.
2. I do not ask AI to generate complete solutions or project code.
3. I do not paste AI-generated code into this repository.
4. I use official documentation as my primary source (Python docs, mySQL docs, library docs).
5. I write down my failed attempts and what I learned from them in ERRORS_AND_LESSONS.md.
6. I ask AI for hints, conceptual explanations or documentation pointers, not final implementations.
7. When I solve a problem, I refactor it only after it already works.
8. Every important mission includes a short post-mortem: what failed, why, and how I fixed it.

## Allowed use of AI

- Explain an error message after I have researched it myself.
- Clarify concepts already covered in official documentation.
- Suggest project ideas or sources of public data.
- Review my own explanation of a concept.
- Ask me Socratic questions that guide my own debugging.
- Point out gaps in test cases or edge cases I have written.
- Review code after I have completed a working version.

## Forbidden use of AI in this phase

- Generating a complete solution to an exercise or mission.
- Writing project code from scratch.
- Solving exercises line by line.
- Producing a ready-to-paste architecture or implementation.
- Debugging for me without me first sharing what I tried.

## Investigation protocol (before asking anyone for help)

1. Understand: rewrite the problem in my own words; define input, process, output.
2. Design: sketch pseudocode or a flow on paper.
3. Attempt: write code without searching for a ready answer.
4. Debug: read the full error, print/inspect values, isolate the problem.
5. Document: record the error, its cause and the fix in ERRORS_AND_LESSONS.md.
6. Consult: only if still stuck — official documentation first, then a hint (not code) from AI or others.

This contract applies fully during Phases 0 to 6. From Phase 7 onward, once fundamentals are solid, AI assistance may be used more like a professional tool (drafting, reviewing), always understood and validated by me first.
