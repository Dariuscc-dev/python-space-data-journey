# Steps to activate a virtual environment in Python

First thing that we have to do if we want to generate a virtual environment to isolate a specific python project/repository is to go to our specific Terminal of our OS and locate ourselves in the folder where we have our project through =

```powershell
cd your/folder/path
```

Next, we proceed to create the actual virtual environment with =

``` powershell
python -m venv venv
```
