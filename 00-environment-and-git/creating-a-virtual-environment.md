# Steps to activate a virtual environment in Python

The first thing that we have to do if we want to generate a virtual environment to isolate a specific python project/repository is to go to our specific Terminal of our OS and locate ourselves in the folder where we have our project, as I'm on Windowns, I have to go  through =

```powershell
cd your/folder/path
```

Next, we proceed to create the actual virtual environment with =

```powershell
python -m venv venv
```

```powershell
venv\Scripts\activate
```

At last, we must get an answer like this one =

```powershell
(venv) C:\Users\Darius Chiosa Chiosa\python-space-data-journey>
```
