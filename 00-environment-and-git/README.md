# Phase 0 — Environment and Git

## Goal

Prepare the lab before learning "programming". Learn to install, run, break and repair my own development environment, and to use Git as a real workflow, not just the GitHub web UI.

## Why this matters

Every future script, pipeline or API depends on a working environment: Python installed correctly, a way to isolate dependencies per project, and a version control habit that protects my work and documents my progress.

## Source material

- Official Python documentation (installation and setup)
- Official Git documentation
- My own notes and trial and error

## Contents

- Installing Python and checking the version from a terminal
- Running a `.py` file from the terminal
- Creating and activating virtual environments (`venv`)
- Installing packages with `pip`
- Understanding `.gitignore`
- Git basics: `init`, `status`, `add`, `commit`, `push`, `pull`, `log`
- Reading and interpreting a Python traceback

## Final mission: python-launchpad

A terminal tool that:

- Takes a target mission date and time as input
- Calculates and displays a countdown
- Validates the input and handles basic errors
- Saves each query to a text file
