# Basic & Essential Git Commands

| Command | Description |
| :--- | :--- |
| `git init` | Initializes a new Git repository in the current folder. |
| `git status` | Shows which files have changed and are staged for commit. |
| `git add .` | Stages all changes for the next commit. |
| `git commit -m "..."` | Records a snapshot of changes with a descriptive message. |
| `git push` | Uploads local commits to the remote repository (e.g., GitHub). |
| `git pull` | Downloads and merges changes from the remote repository. |
| `git log` | Displays the chronological history of commits. |
