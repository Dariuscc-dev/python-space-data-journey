# Understaing a Python traceback

A Python traceback, is a response that you will get when the code that you've developed has errors like an incorrect syntaxis.

It contains information about the error like what type of error it is, where it is located and sometimes, event hints about a possible solution.

Here's an example =

```python       
PS C:\Users\Darius Chiosa Chiosa\python-space-data-journey> python 00-environment-and-git/test.py
  File "C:\Users\Darius Chiosa Chiosa\python-space-data-journey\00-environment-and-git\test.py", line 5
    print ("My name is Darius, what about yours?)
           ^
SyntaxError: unterminated string literal (detected at line 5)
```
