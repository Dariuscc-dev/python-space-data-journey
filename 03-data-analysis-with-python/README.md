# Phase 3 — Data Analysis with Python

## Goal

Use data to answer real questions, not just to print it: statistics, NumPy, Pandas and visualisation.

## Source material

- 30 Days of Python (Asabeneh): days 24-25 as a starting checklist for statistics and Pandas
- Official Pandas and NumPy documentation
- Matplotlib / Plotly documentation

## Contents

- Descriptive statistics basics
- NumPy arrays and vectorised operations
- Pandas: DataFrames, filtering, groupby, merge, pivot
- Data cleaning: nulls, duplicates, type coercion
- Visualisation: Matplotlib, Seaborn, Plotly
- Jupyter Notebook as an exploratory report, not as the place all code lives

## Final mission: Earth & Space Data Explorer

An exploratory data analysis (EDA) notebook on a fascinating public dataset of my choice: meteorites, exoplanets, space launches, earthquakes, volcanic activity or extreme weather. The notebook should end with clear questions answered, not just plots.

SQL starts here in parallel (see Phase 4): SELECT, WHERE, GROUP BY, basic JOIN.
