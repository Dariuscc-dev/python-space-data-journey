# Phase 4 — SQL for Data

## Goal

Learn to model the world in related tables and ask powerful questions of data. SQL is the other half of a real data system: Python collects, transforms and automates; SQL persists, relates and queries.

## Source material

- Official PostgreSQL tutorial (createdb, tables, queries, joins, aggregations, views, foreign keys, transactions, window functions)
- SQLite documentation for lightweight local practice

## Contents

- Relational modelling: entities, keys, relationships
- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions
- JOINs (inner, left, right)
- Subqueries and CTEs (WITH)
- Window functions
- SQLite for quick practice, PostgreSQL for the real mission

## Final mission: Flight Data Warehouse

A relational model of airports, airlines, aircraft, routes, flights and delays. I design the schema myself on paper first, then create the tables, load data, and write queries that answer real questions (busiest routes, most delayed airports, punctuality by airline, patterns by month or time of day).
